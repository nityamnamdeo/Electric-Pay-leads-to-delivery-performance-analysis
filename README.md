# Project: Excel Analysis - EPe BA intern workbook

This repository contains exported sheets and analysis from the Excel workbook EPe Business analysis(AutoRecovered).xlsx.

## Files included
- Raw data.csv — original record-level dataset (transactions/events).
- Calculations.csv — intermediate calculated fields and percentage metrics used in reporting.
- DashBoard.csv — summary KPIs and chart-source data.
- sheets_report.csv — sheet-level metadata (rows/cols/pivot/chart counts).
- excel_summary.json — programmatic summary for reproducibility.

## Overview
This workbook demonstrates the end-to-end process of turning raw transactional data into business insights using Excel:
1. Clean and prepare raw data (Raw data sheet).
2. Create derived metrics and percentage calculations (Calculations sheet).
3. Build KPI summaries and charts for executive dashboards (DashBoard sheet).

## Key insights (examples — replace with actual numbers)

- Month-over-Month revenue growth: Y%.
- Conversion rate (calculated): Z%.
